# 车门助手 · 特斯拉蓝牙助手

通过 iPhone 附近蓝牙控制特斯拉车辆的车门、车锁、温控和充电等功能，无需登录特斯拉账号。

本仓库提供 **IPA 安装包及使用说明**。当前版本 **0.3.2**（构建号 7），需要 **iOS 17.0 或更高版本**。

## 0.3.2 更新内容

相对于仓库原有的 0.3.0，本次包含 0.3.1 和 0.3.2 的更新：

- **多车型入口**：VIN 识别放开至 Model 3 / Y / S / X，界面显示对应车型。此为软件适配入口，不代表所有车型、年款和功能均已实车验证；老款 S / X 可能不支持所需蓝牙协议，具体操作受车辆硬件和固件限制。
- **多车辆管理**：保存车辆、命名和切换；配对钥匙按 VIN 分别保存，迁移旧版验证记录。
- **刷新提速**：优先读取电量、里程、门锁和温度；其他类别按 15 分钟间隔更新。分批显示结果及用时，操作请求可在当前读取结束后优先执行。
- **车门状态修复**：安全模块操作后补读状态；有车门或行李厢打开时短时跟踪状态，减少手动关门后界面仍显示打开的问题。
- **温控优化**：空调、除霜、方向盘和车窗通风使用独立开关；需要时先开启空调；座椅加热、通风采用更清楚的模式按钮和档位显示。
- **更多操作**：闪灯次数选择、远程启动（免钥匙驾驶）、唤醒车辆、保持配件供电；均通过附近蓝牙执行，“远程启动”不代表支持远距离联网控制。
- **界面与流畅度**：统一细线图标，车门俯视图高亮，缓存图标和车图解析结果；总里程及本地行驶记录移至“更多”。

新增功能及多车型表现仍需更多实车验证。当前不包含 Fleet API 云端控制、豆包语音、导航发送或后台持续行程记录。

## 首次使用与配对

1. 在车旁打开 App，允许蓝牙访问。
2. 进入「设置与配对」，输入车辆的 **17 位 VIN**。
3. 坐进车内，点击「发送配对请求」，按车机提示刷卡确认。
4. 点击「验证钥匙」，握手成功后即可使用车辆控制。

可在设置中的“我的车辆”保存、命名和切换车辆。每辆车使用在设备上随机生成的钥匙，保存在本机钥匙串，不随 iCloud 同步。更换手机需重新配对；撤销访问时，在车机钥匙列表中删除对应钥匙。

## 常用操作

- **车辆控制**：连接成功后，在车辆页选择车锁、前后备箱或对应车门；涉及确认的操作按界面提示完成。
- **温控**：调节温度、电流和座椅时，停手后发送；充电上限在松手后发送。已有指令执行时，新调节会排队。
- **刷新车况**：页面支持下拉刷新，读取电量、温度、胎压等信息。某类读取失败时保留上次数据；未曾读到的数据以「—」显示。
- **找车**：授予「使用 App 时」定位权限后，查看车辆最近一次读取的位置、距离和方向，也可打开地图步行导航。位置依赖刷新，不代表车辆实时位置。
- **行驶记录**：两次刷新之间的里程差计为一段，仅保存在本机；不等同于持续自动记录的完整行程。
- **快捷指令**：可使用「释放特斯拉车门」「控制特斯拉」动作，并按系统支持绑定到操作按钮、控制中心或桌面快捷指令。

## 蓝牙连接说明

App 通过附近蓝牙工作，需要靠近车辆。回到前台会尝试预连接；闲置约 60 秒、进入后台或锁屏时断开，不在后台持续轮询。

车门、车锁、前后备箱和充电口控制走车辆安全模块；温控、充电、媒体和部分车况读取需要车机，可能唤醒车辆。

## 更新与钥匙

使用相同应用标识、签名身份和钥匙串权限覆盖安装时，可能保留原配对资料。更换签名团队、应用标识、手机或重新安装后，不保证旧钥匙仍可访问，需要时重新配对。

请随身携带卡片钥匙。签名过期、证书失效、手机电量不足或蓝牙连接异常时，App 可能无法使用。

## 常见问题

**IPA 为什么不能直接安装？**

这是供自行签名使用的安装包，需要先完成有效签名并通过对应工具安装。

**提示无法验证 App，或安装后打不开？**

检查签名有效期、设备授权以及签名工具的提示；需要时重新签名安装。

**连接慢或找不到车辆？**

确认已允许蓝牙、VIN 输入正确、车辆距离足够近，并已在车机完成配对确认。信号较弱或车辆休眠时，部分操作可能较慢。

**找车位置或行驶记录不更新？**

这些信息依赖车况刷新。找车还需要定位权限；它们不在后台持续自动更新。

**部分按钮没有效果？**

先检查蓝牙连接和车辆配置。既有 Model 3 版本验证过开门、车锁、前后备箱、充电口、空调、座椅与方向盘等操作。0.3.1 / 0.3.2 新增及改动部分尚未完成实车验证，不能将既有验证范围视为 Model Y / S / X 的兼容保证。

**支持桌面小组件、灵动岛或 Apple Watch 吗？**

当前安装包未提供这些扩展。
